Date: 2026-08-05

New paid model calls: 0

## Purpose

Historical model-backed Level 1 receipts can already aggregate through the Fleet controller, but those source runs predate the Fleet plan. This checkpoint freezes a genuinely prospective experiment: the Fleet plan and exact selected specialists exist before three fresh role tasks are released or executed.

## Frozen chain

The campaign plan binds:

- the trusted customer-local intake receipt and bounded fleet contract;
- the independently verified selected Fleet plan;
- exact assignment ids and hashes;
- the actual admitted procurement, support and RevOps Level 1 selections;
- candidate ids, fingerprints and selection-record hashes;
- exact independent verifier and model per assignment;
- per-task cost and latency limits;
- a three-task sealed-vault digest without case ids or payloads;
- a maximum of three task evaluations and 72 model turns; and
- the current pricing-table hash and a **$1.30** frozen Fleet spend ceiling.

The plan has zero execution, model-spend, role-creation and activation authority.

## Independent authorization gates

Vault release requires all of the following at the same time:

- global paid-model approval;
- the prospective-Fleet-specific approval phrase;
- the exact frozen plan hash;
- an explicit positive limit no greater than $1.30;
- same-day pricing confirmation;
- the exact pricing-table hash; and
- an API key.

Removing any gate fails closed. A different plan hash cannot release the vault.

## Zero-cost discriminating preflight

Before sealing the checkpoint, each fresh fictional task world was executed only with deterministic reference and do-nothing controls:

- procurement reference passed; do-nothing failed;
- support reference passed; do-nothing failed; and
- RevOps reference passed; do-nothing failed.

The vault remained sealed throughout. No task id appeared in the campaign plan.

## Result

- Exact selected specialists bound: **3**
- Fresh sealed tasks: **3**
- Structural task ceiling: **3**
- Structural model-turn ceiling: **72**
- Frozen hard spend ceiling: **$1.30**
- Deterministic reference/control checks: **6/6**
- Full local suite: **239/239 passing**
- New calls/spend: **0 / $0**

## Evidence boundary

This is a prospective, leakage-resistant and authorization-bound experiment plan. It does not show that any selected model agent passes the fresh tasks, that three specialists coordinate successfully in a forward run, or that the parent goal completes model-backed. The empirical Level 2 result still requires a resumable paid runner and Joel's explicit approval to execute this exact plan.
